# 双设备网络检测程序

程序从路由器客户端列表中同时检测两台目标设备，并提供本地 Web 看板、RSSI 趋势、ARP 连通性检查、历史记录和状态通知。

## 启动

1. 建议使用 Python 3.10 或更高版本创建虚拟环境。
2. 安装依赖：`python -m pip install -r requirements.txt`
3. 运行：`python main.py`
4. 浏览器访问：`http://127.0.0.1:30707`

如需使用 ARP 检测，还需在系统中安装 Nmap，并确保 `nmap` 命令可用。

## 配置两个设备

在首页“目标设备设置”中分别配置设备一和设备二。每台设备可按 MAC 地址或名称包含文字匹配，推荐优先填写 MAC 地址，避免同名设备误匹配。保存后无需重启，下一轮扫描即使用新配置。

两个设备分别维护在线状态、ARP 连续失败次数、告警等级和历史记录；其中任意设备离线时会自动使用较短的扫描间隔。

## 测试

运行：`python -m unittest discover -s tests -v`

## 常见问题

如果日志提示“路由器已有其他管理员会话，已达到登录上限”，请在浏览器中退出路由器管理后台（仅关闭标签页可能不会立即注销），等待程序下一轮自动登录。程序在登录失败期间会保留最后一次有效设备状态，不会把设备误判为下线。

如果持续提示“响应中没有客户端 JSON 或表格”，请在首页确认“路由器地址”和“数据接口路径”与当前固件一致。程序会将登录页、会话超时页与真正的数据解析错误分别记录。
